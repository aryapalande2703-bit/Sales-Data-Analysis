# Sales Data Analysis

## Project Overview
This beginner-friendly data analytics project explores sales and profit performance using a Superstore dataset. The goal is to identify business trends and turn data into useful insights.

## Project Objectives
- Analyse overall sales and profit.
- Compare sales and profit across product categories.
- Identify high-performing and low-performing products.
- Explore business trends and support data-driven decisions.

## Tools Used
- **Microsoft Excel:** Data cleaning and initial analysis
- **SQL:** Data aggregation, filtering and business analysis
- **Power BI:** Planned interactive dashboard

## Dataset
The project uses a Superstore sales dataset containing order and product information, including sales, profit, quantity and category.

## SQL Analysis
The SQL queries are available in the [`sql_queries`](sql_queries/) folder.

1. `01_overall_sales_profit.sql` — calculates overall sales, profit and record count.
2. `02_category_sales.sql` — compares sales across product categories.
3. `03_category_profit.sql` — compares profit across product categories.

## Initial Findings
- Technology recorded the highest total sales among the product categories.
- Technology also recorded the highest total profit among the product categories.

These findings will be expanded as the analysis progresses.
